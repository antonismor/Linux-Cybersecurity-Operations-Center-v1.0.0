# Android Agent

This directory contains the Android deployment-source placeholder for Linux Cybersecurity Operations Center v1.0.0.

The Debian 13 controller publishes this directory as a downloadable source bundle from the Agent Downloads section.

A production Android APK/AAB requires:

- Android SDK
- Gradle
- package/application identity
- application signing
- organization-specific deployment policy
- optionally Device Owner / DPC capabilities
- optionally managed VPN telemetry

The project does not label an unsigned source bundle as a finished production APK.
